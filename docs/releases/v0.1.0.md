# WorldSimSeed v0.1.0

WorldSimSeed v0.1.0 is the first released baseline of the project: a small deterministic simulation runtime for data-defined worlds that can run headlessly in Node.js or in a browser Worker.

## What is included

- restricted YAML / JSON-compatible world specs
- structural and semantic validation with fail-closed unknown-field handling
- allowlisted expression evaluation with no arbitrary JavaScript execution
- deterministic seeded simulation core
- agents, world state, discrete steps, events, effects, and observers
- reproducibility manifests with engine/random-model version, spec hash, seed, parameters, limits, and completion status
- single-run CLI and deterministic batch experiments
- browser Worker adapter and minimal `<world-sim>` Web Component
- live GitHub Pages demo: https://yo4e.github.io/WorldSimSeed/
- three sample worlds and a Talent × Luck reference experiment
- Node/Chromium parity, security-negative, package, dependency-audit, and resource-limit release gates

## Determinism and reproducibility

A completed run is deterministic relative to the validated world spec, resolved parameters, WorldSimSeed engine version, random-model identifier, seed, step count, observers, and effective limits. Node/headless and Chromium Worker execution share the same portable simulation semantics and are checked against the same-seed acceptance fixture in CI.

The v0.1.0 engine version recorded in run manifests is `0.1.0`. The random model identifier is `keyed-fnv1a-mulberry32-v1`.

## Security boundary

World specs are treated as untrusted data, not executable host code. v0.1 does not allow arbitrary JavaScript, filesystem/process access, spec-driven networking, imports/includes, recursion, user-defined loops, or host-object access. Expression evaluation is allowlisted, dangerous property names are rejected, and runtime work is bounded by finite host-controlled resource limits.

Default host ceilings are:

```text
maxAgents       5,000
maxSteps          500
maxRuns           100
maxEvents   1,000,000
maxTraceRecords 50,000
```

`<world-sim>` uses `maxRuns = 1`.

See [security-model.md](../security-model.md) and [known-limitations-v0.1.md](../known-limitations-v0.1.md) for the exact boundary.

## Distribution

v0.1.0 is released through GitHub source/tag/Release and the live GitHub Pages demo. `package.json` remains `private: true`, and this release is **not published to npm**.

## Known limitations

v0.1 intentionally stays narrow. It does not provide networks/spatial models, dynamic agent creation, mid-run parameter intervention, distributed/streaming batch execution, a hard wall-clock kill inside the portable Node core, or a rich visualization framework. See the known-limitations document for the full list.
