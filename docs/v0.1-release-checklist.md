## World-spec contract

- [x] world spec v0.1 is versioned and documented as the released v0.1.0 contract.
- [x] YAML authoring / JSON-compatible canonical model / JSON Schema artifact strategy is documented.
- [x] unsupported/unknown fields fail closed under the runtime validator.
- [x] expression operator/function allowlist is documented and enforced.
- [x] state/parameter path rules are documented and enforced.
- [x] arbitrary JavaScript, host-object access, dynamic imports, recursion, and user-defined unbounded loops are not expressible.
- [x] three materially different sample worlds pass runtime validation and JSON Schema artifact conformance.
- [x] shared positive/negative fixtures exercise JSON Schema artifact ↔ runtime structural parity in CI.

## Runtime and security

- [x] Threat model and trust boundaries are documented as the released v0.1 boundary.
- [x] Untrusted world specs are the default security assumption.
- [x] Resource-limit categories and ownership are defined.
- [x] Conservative finite numeric defaults are selected from recorded Node/Chromium benchmark evidence.
- [x] Runtime enforces agent, step, batch-run, event, and retained-trace limits.
- [x] Browser host can cooperatively abort a Worker run and later resume it deterministically.
- [x] Limit termination returns a typed `RESOURCE_LIMIT` error with safe structured details.
- [x] Prototype/property escape negative tests exist.
- [x] Unsupported-operation and malformed-spec negative tests exist.
- [x] There is no spec-driven network/filesystem/import path.
- [x] Browser execution uses a Worker and chunk yielding; CI verifies main-thread responsiveness during a representative run.
- [x] Remaining wall-clock/output-byte limitations are explicitly documented rather than implied away.

## Reproducibility

- [x] Same validated spec + resolved parameters + engine/random-model version + seed + steps has a deterministic result contract.
- [x] Run manifest records engine/random-model version, spec version/hash, concrete seed, resolved parameters, active limits, observer IDs, trace state, and completed status.
- [x] v0.1.0 run manifests report engine version `0.1.0`.
- [x] Provenance timestamp policy is explicit: host metadata may carry timestamps outside the deterministic engine manifest.
- [x] Seed derivation and uint32 overflow rejection for batch runs are documented and tested.
- [x] Browser Worker and headless execution agree on the deterministic acceptance fixture in Chromium CI.
