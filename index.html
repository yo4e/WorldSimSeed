Write the rules, run the world, and inspect what emerges. This page runs the real WorldSimSeed browser runtime locally in your browser with a module Worker. No simulation server is involved.

Try a run, change the seed, then return to 42. The same world + seed reproduces the same deterministic result.

Talent and luck sample simulation

  1. Step advances one tick so you can inspect the world incrementally.
  2. Run finishes the configured simulation inside a Worker without owning the main thread.
  3. Reset returns to the selected seed. The metrics are deterministic for the same validated world and seed.

This is the v0.1 Talent × Luck reference world. World specs are data, not executable JavaScript. The browser host fetches the YAML with credentials omitted, validates it, and sends execution to the same portable simulation layer used by the headless runtime.
